## 📌 Tentang Proyek

**Social Network Knowledge Hub** adalah web interaktif komprehensif yang dirancang untuk memfasilitasi riset dan eksplorasi mendalam di bidang **Social Network Analysis (SNA)**, **Teori Graf**, **Network Science**, dan **Graph Neural Networks (GNN)**.

Proyek ini dilengkapi dengan **Profesor Riset AI (Research Co-Pilot Workbench)** — agent kecerdasan buatan terpersonalisasi berbasis Google Gemini yang dilengkapi *Google Search Grounding real-time* untuk membantu peneliti menemukan celah riset (*Research Gap*), mengidentifikasi paradoks literatur, serta menghubungkan analisis jaringan dengan berbagai disiplin ilmu (Epidemiologi, Keuangan, Keamanan Siber, Sosiologi, dll).

🌐 **Akses Live Website**: [https://hedwigka.github.io/social-network-ai/](https://hedwigka.github.io/social-network-ai/)

## ✨ Fitur-Fitur Utama

### 🎨 1. Desain Interaktif & Visual Excellence
- Interface berbasis **Modern Glassmorphism** dengan Tailwind CSS.
- Responsif di seluruh perangkat (Desktop, Tablet, & Smartphone).
- Render presisi untuk formula matematika Teori Graf menggunakan **KaTeX**.

### ⚛️ 2. Force-Directed Graph Physics Simulator (D3.js)
- Simulator fisika interaktif untuk memanipulasi simpul (*nodes*) dan sisi (*links*) secara *real-time*.
- Eksperimen topologi graf: Ring, Star, Grid, Clique (Complete Graph), Scale-Free Network (Barabási-Albert), dan Random Graph (Erdős–Rényi).
- Fitur kalkulasi otomatis metrik topologis (Kepadatan, Jumlah Simpul, Keterhubungan).

### 🧪 3. Visualizer Algoritma Step-by-Step
- Visualisasi tahapan eksekusi **Breadth-First Search (BFS)** dan **Algoritma Dijkstra** (Shortest Path).
- Demonstrasi visual paradigma **Message Passing** pada Graph Neural Networks (GCN, GAT, GraphSAGE).

### 🤖 4. Profesor Riset AI (Research Co-Pilot Workbench)
Agent AI interaktif berbasis Gemini API yang memiliki **5 Mode Riset Proaktif**:
1. 🔬 **Research Gap Scanner**: Memindai area riset SNA yang belum tersentuh & mengidentifikasi sudut kebaruan (*novelty*).
2. 🌉 **Cross-Disciplinary Bridge Builder**: Memetakan penerapan SNA ke disiplin ilmu lain (Epidemiologi, Keuangan/Fraud, Kriminologi, Sosiologi, Pendidikan).
3. 🧪 **Paradox & Contradiction Detector**: Menganalisis kontradiksi hasil riset & perdebatan metodologis.
4. 📋 **Research Question Generator**: Merumuskan 3-5 *Research Questions* (RQ) skripsi lengkap dengan *Skor Novelty (1-10)*.
5. 📊 **Literature Landscape & Trend Monitor**: Memantau tren publikasi *hot* vs *declining* tahun 2024-2026 secara *real-time* via Google Search Grounding.

### 🎛️ 5. Dynamic Model & API Key Management
- Modal antarmuka untuk menyimpan Gemini API Key secara lokal (`localStorage`).
- Bebas memilih model AI (`Gemini 3 Flash Preview`, `Gemini 2.5 Pro`, `Gemini 2.5 Flash`, dll).
- Tombol **Uji Koneksi API** instan dari antarmuka web.
- Fitur **Ekspor Catatan Riset (.md)** untuk mengunduh seluruh hasil diskusi riset ke dalam format Markdown.

## 🚀 Panduan Penggunaan Lokal

1. **Clone Repository**:
   ```bash
   git clone https://github.com/HedwigKA/social-network-ai.git
   cd social-network-ai
   ```

2. **Jalankan Website**:
   Buka file `index.html` di browser Anda (tidak memerlukan server backend khusus).

3. **Gunakan Profesor Riset AI**:
   - Klik tombol **🔑 Model & Key** di navigasi kanan atas.
   - Dapatkan API Key gratis di [Google AI Studio](https://aistudio.google.com/app/apikey).
   - Tempel API Key Anda, klik **Uji Koneksi API**, lalu simpan.
