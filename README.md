## 📌 About The Project

**Social Network Knowledge Hub** is a comprehensive interactive web application designed to facilitate deep exploration and research in **Social Network Analysis (SNA)**, **Graph Theory**, **Network Science**, and **Graph Neural Networks (GNN)**.

The project features a **Personalized AI Research Professor (Research Co-Pilot Workbench)** powered by Google Gemini with *real-time Google Search Grounding*. It assists researchers and computer science students in uncovering unexplored **Research Gaps**, identifying academic paradoxes & contradictions, formulating research questions, and mapping network science concepts across multidisciplinary domains (e.g., Epidemiology, Finance/Fraud Detection, Cybersecurity, Sociology, and Computational Social Science).

🌐 **Access Live Application**: [https://hedwigka.github.io/social-network-ai/](https://hedwigka.github.io/social-network-ai/)

## ✨ Key Features

### 🎨 1. Premium Glassmorphism Design & UX
- Modern Glassmorphism UI built with **Tailwind CSS**.
- Fully responsive across desktop, tablet, and mobile browsers.
- Precise LaTeX mathematical formatting for Graph Theory formulas using **KaTeX**.

### ⚛️ 2. Force-Directed Graph Physics Simulator (D3.js)
- Real-time interactive physics engine to manipulate graph nodes and edges.
- Generative graph topology presets: Ring, Star, Grid, Clique (Complete Graph), Scale-Free Networks (Barabási-Albert), and Random Graphs (Erdős–Rényi).
- Automated topological calculations: Density, Node Centrality, and Component Connectivity.

### 🧪 3. Step-by-Step Algorithm Visualizers
- Interactive execution steps for **Breadth-First Search (BFS)** and **Dijkstra's Algorithm** (Shortest Path).
- Visual demonstrations of the **Message Passing Paradigm** in Graph Neural Networks (GCN, GAT, GraphSAGE).

### 🤖 4. AI Research Professor (5-Mode Workbench)
Interactive Research Agent featuring **5 Proactive Modes**:
1. 🔬 **Research Gap Scanner**: Scans recent literature to spot unaddressed research gaps & evaluate novelty.
2. 🌉 **Cross-Disciplinary Bridge Builder**: Maps SNA concepts to other fields (Epidemiology, Financial Fraud Rings, Political Echo Chambers, Cyberbullying).
3. 🧪 **Paradox & Contradiction Detector**: Analyzes conflicting academic findings, methodological debates (e.g., Homophily vs Social Influence), and scalability limits.
4. 📋 **Research Question Generator**: Formulates 3-5 thesis/paper Research Questions (RQs) with a **Novelty Score (1-10)** and methodology recommendations.
5. 📊 **Literature & Trend Monitor**: Tracks trending vs declining SNA research topics (2024–2026) via real-time web search grounding.

### 🎛️ 5. Dynamic Model & API Key Configuration
- Secure UI modal to configure your Gemini API Key locally in `localStorage`.
- Runtime model switching (`Gemini 3 Flash Preview`, `Gemini 2.5 Pro`, `Gemini 2.5 Flash`, or custom model IDs).
- One-click **API Connection Test** directly from the UI.
- **Export Research Notes (.md)**: Download your entire AI research session into a formatted Markdown document for paper writing.

## 🚀 Local Getting Started

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/HedwigKA/social-network-ai.git
   cd social-network-ai
   ```

2. **Run Locally**:
   Open `index.html` in any web browser (no backend server installation required).

3. **Configure AI Professor**:
   - Click the **🔑 Model & Key** button in the top navigation bar.
   - Obtain a free API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
   - Paste your API key, click **Test API Connection**, and save.

## 🌐 Deploying to GitHub Pages

This repository is optimized for **GitHub Pages**:
1. Go to your repository on GitHub: `Settings` > `Pages`.
2. Under **Build and deployment** > **Source**, choose `Deploy from a branch`.
3. Select branch `main` and folder `/ (root)`, then click **Save**.
4. The live site will be deployed at `https://HedwigKA.github.io/social-network-ai/`.
