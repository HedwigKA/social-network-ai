# 🕸️ Social Network Knowledge Hub & Profesor Riset AI

Aplikasi Web Interaktif & Simulator Pembelajaran **Social Network Analysis (SNA)**, Teori Graf, Network Science, dan Graph Machine Learning untuk Informatika.

Dilengkapi dengan **Profesor Riset AI (Research Co-Pilot Workbench)** berbasis **Gemini 3 / 2.5** yang dilengkapi *Google Search Grounding real-time* untuk membantu peneliti merumuskan hipotesis, menemukan celah riset (*Research Gap*), mengidentifikasi paradoks literatur, serta memetakan aplikasi SNA lintas disiplin ilmu.

---

## ✨ Fitur Utama

- 🎨 **Interaktif & Visual Excellence**: Desain Glassmorphism modern dengan dukungan dark/light mode dan animasi dinamis.
- 📐 **Formula Matematika Teori Graf**: Rendering notasi aljabar linier dan Teori Graf secara presisi dengan **KaTeX**.
- ⚛️ **Simulator Fisika Graf (D3.js)**: Engine simulasi *Force-Directed Graph* interaktif untuk eksperimen topologi jaringan.
- 🧪 **Visualizer Algoritma Step-by-Step**: Demonstrasi algoritma BFS, Dijkstra, dan Message Passing pada Graph Neural Networks (GNN).
- 🤖 **Profesor Riset AI (5 Mode Co-Pilot)**:
  - 🔬 **Research Gap Scanner**: Mengidentifikasi area riset SNA yang belum tersentuh.
  - 🌉 **Cross-Disciplinary Bridge Builder**: Memetakan aplikasi SNA ke disiplin ilmu lain (Epidemiologi, Keuangan/Fraud, Sosiologi, dll).
  - 🧪 **Paradox Detector**: Menganalisis kontradiksi hasil riset & perdebatan metode.
  - 📋 **Research Question Generator**: Menyusun 3-5 RQ skripsi lengkap dengan *Skor Novelty (1-10)*.
  - 📊 **Literature & Trend Monitor**: Memantau tren riset *hot/declining* 2024-2026 secara real-time.
- 🎛️ **Dynamic Model & Key Selector**: Modal interaktif untuk mengatur Gemini API Key dan memilih model (`Gemini 3 Flash`, `Gemini 2.5 Pro`, dll).
- 📥 **Ekspor Sesi Riset (.md)**: Mengunduh catatan diskusi riset menjadi dokumen Markdown.

## 🚀 Cara Menjalankan Secara Lokal

1. Clone repository ini:
   ```bash
   git clone https://github.com/USERNAME/REPOSITORY-NAME.git
   cd REPOSITORY-NAME
   ```
2. Buka berkas `index.html` di browser favorit Anda (Chrome / Firefox / Edge / Safari).
3. Untuk menggunakan fitur **Profesor Riset AI**, klik tombol **🔑 Model & Key** di navigasi kanan atas dan masukkan API Key dari [Google AI Studio](https://aistudio.google.com/app/apikey).

---

## 🌐 Deploy Online (GitHub Pages)

Web ini dirancang agar dapat diakses dari mana saja secara gratis melalui **GitHub Pages**:
1. Buka Repository ini di GitHub.
2. Masuk ke menu **Settings** > **Pages**.
3. Pada bagian **Build and deployment** > **Source**, pilih `Deploy from a branch`.
4. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Situs web Anda akan aktif secara online dalam beberapa detik!
